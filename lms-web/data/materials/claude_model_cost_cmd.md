# /model과 /cost — 두뇌 고르기와 사용량 확인
> 원본: claude_model_cost_cmd.pdf · 난이도: ★☆☆(지금 필요)

## 한 줄 요약
`/model`은 이번 대화에서 쓸 Claude의 "두뇌"(Opus/Sonnet/Haiku)를 고르는 명령이고, `/cost`는 지금까지 쓴 토큰과 비용을 확인하는 명령이다.

## 이게 뭐예요?
자동차에 에코 모드와 스포츠 모드가 있는 것처럼, Claude Code에도 여러 모델(두뇌)이 있어요. Opus는 가장 똑똑하지만 비싸고 느린 편, Sonnet은 일상 작업에 알맞은 균형형, Haiku는 빠르고 저렴한 경량형이에요. `/model`로 이 두뇌를 바꿀 수 있고, 모델마다 비용·추론 능력·속도·컨텍스트 창 크기(한 번에 기억할 수 있는 양)가 달라요. `/cost`는 계기판의 연비 표시처럼, 이번 세션에서 토큰(AI가 글을 세는 단위)을 얼마나 썼고 비용이 얼마인지 보여줘요.

## 핵심 정리
- `/model` = 현재 세션에서 사용할 LLM(대형 언어 모델) 변경. "어떤 두뇌로 대화할지" 결정
- 모델별 차이 4가지: 💰 비용, 🧠 추론 능력, ⚡ 속도, 📚 컨텍스트 창 크기
- 고르는 기준(실용 가이드):
  - 일상 개발·간단한 코드 수정·빠른 반복 → **Sonnet**
  - 아키텍처 설계·깊은 추론·복잡한 디버깅·아주 큰 저장소 → **Opus**
  - 비용이 민감한 작업 → **Sonnet** (또는 Haiku)
- `/cost` = 현재 세션의 누적 토큰·예상 비용·코드 변경량 표시 (Total cost, duration, input/output 토큰 등)
- 비용이 커지는 경우: 대화(컨텍스트)가 아주 길어질 때, 큰 코드베이스를 통째로 붙여넣을 때, 큰 파일을 반복 분석할 때, Opus 같은 상위 모델을 쓸 때
- 정액제(Claude Max 등) 사용자는 소소한 사용은 걱정 없지만, 아주 무거운 세션이 반복되면 한도(limit)에 걸릴 수 있음 → https://claude.ai/settings/usage 에서 확인

## 따라해보기
1. `/model` — 모델 선택 화면을 열고 Sonnet으로 바꿔보기 (Enter로 확정, Esc로 취소)
2. `/cost` — 지금까지의 토큰 사용량과 예상 비용 확인
3. 긴 작업을 한 뒤 다시 `/cost` — 숫자가 얼마나 늘었는지 비교해보기

## 주의할 점 / 자주 헷갈리는 것
- 비싼 모델 = 항상 좋은 것이 아니에요. 간단한 일에 Opus를 쓰면 돈과 시간 낭비예요. 기본은 Sonnet, 막힐 때 Opus.
- `/model` 변경은 그 세션(과 이후 세션)에 적용돼요. 지금 무슨 모델인지 헷갈리면 다시 `/model`로 확인하세요.
- `/cost`의 금액은 추정치예요. 정액 요금제(Max)라면 달러 표시보다 "사용 한도 %"가 더 중요해요.
- 대화가 길어질수록 매 요청 비용이 커져요. 주제가 바뀌면 `/clear`로 새로 시작하는 게 절약 비결이에요.
