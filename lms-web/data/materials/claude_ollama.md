# Ollama — 내 컴퓨터에서 직접 돌리는 AI
> 원본: claude_ollama.pdf · 난이도: ★★☆(곧 필요)

## 한 줄 요약
Ollama는 인터넷 없이 내 컴퓨터(Mac/Windows/Linux) 안에서 AI 언어 모델을 내려받아 실행하게 해주는 무료 프로그램입니다.

## 이게 뭐예요?
넷플릭스(클라우드 AI)는 인터넷이 있어야 보지만, 다운로드한 영화는 비행기 안에서도 볼 수 있죠. Ollama는 AI 모델을 영화처럼 내 컴퓨터에 "다운로드해서" 돌리는 도구예요. 질문 내용이 외부 서버로 나가지 않으니 사생활이 지켜지고, 사용료도 없습니다. 별명이 "Docker for LLMs"인데, 명령어 한 줄로 모델을 받아서(pull) 실행하는(run) 방식이 닮았기 때문이에요(Docker는 프로그램을 상자째 받아 실행하는 개발 도구).

## 핵심 정리
- 로컬 LLM 런타임(LLM = 대형 언어 모델, 런타임 = 실행시켜 주는 프로그램) — 클라우드 API 불필요
- 프라이버시: 모든 데이터가 내 컴퓨터 안에만 머무름 — 회사 기밀, 개인정보 다룰 때 유리
- 빠른 응답: 네트워크 왕복이 없어서 지연(latency)이 적음
- 비용: API 사용료 0원 (전기료와 컴퓨터 성능만 부담)
- 모델 관리가 간단: `ollama pull`로 받고 `ollama run`으로 실행
- 인기 모델: Llama 3, Gemma, Qwen, Mistral 등 — 골라서 실험하기 좋음
- 터미널(CLI)로도, 프로그램에서 부르는 API로도 사용 가능

## 따라해보기
1. Ollama 설치 (Mac) — Homebrew라는 설치 도우미로 한 줄 설치
   ```
   brew install ollama
   ```
2. 모델 내려받기 — Llama 3 모델 파일을 내 컴퓨터로 다운로드
   ```
   ollama pull llama3
   ```
3. 모델과 대화 시작 — 터미널에서 바로 채팅 (끝낼 땐 /bye 입력)
   ```
   ollama run llama3
   ```

## 주의할 점 / 자주 헷갈리는 것
- 모델 파일이 수 GB로 큽니다 — 디스크 여유 공간과 다운로드 시간을 확인하세요
- 컴퓨터 사양(특히 메모리)이 낮으면 느리거나 큰 모델이 안 돌아갈 수 있어요
- 로컬 소형 모델은 Claude 같은 대형 클라우드 모델보다 답변 품질이 낮은 게 보통입니다 — 용도에 맞게 선택
- "무료 = 공짜"는 API 요금 얘기일 뿐, 전기와 컴퓨터 자원은 소모됩니다
