# 스킬(Skills) — 클로드에게 가르치는 "업무 매뉴얼"
> 원본: claude_skills_command.pdf · 난이도: ★☆☆(지금 필요)

## 한 줄 요약
스킬은 "이런 요청이 오면 이 순서대로 해"라고 미리 적어 두는 작은 매뉴얼 파일로, `/스킬이름`으로 바로 부를 수 있다.

## 이게 뭐예요?
새 직원에게 매번 말로 일을 설명하는 대신, 잘 정리된 업무 매뉴얼을 한 권 주는 것과 같아요.
스킬은 클로드가 특정 작업을 할 때 따라야 할 규칙과 순서를 적어 둔 마크다운 파일(SKILL.md)이에요.
클로드는 평소엔 매뉴얼을 펼치지 않다가, 관련 요청이 들어올 때만 그 매뉴얼을 읽어서 따라 합니다.
덕분에 매번 똑같이 길게 설명할 필요가 없고, 결과도 항상 일정해져요.

## 핵심 정리
- 스킬 = 클로드의 능력을 확장하는 **모듈식 지시문**(필요할 때만 불러오는 작은 매뉴얼).
- 두 가지 사용 방법:
  - **자동 호출**: 클로드가 내 요청을 보고 관련 스킬을 알아서 골라 적용
  - **수동 호출**: 내가 `/skill-name` 처럼 슬래시 명령으로 직접 실행
- 스킬 폴더 구조: `SKILL-NAME/SKILL.md` 한 파일이 기본.
- SKILL.md 구성: 맨 위 **YAML frontmatter**(이름·설명 등 메타데이터를 적는 머리말) + 아래 마크다운 지시문.
- `description`(설명)을 잘 써야 클로드가 "언제 이 스킬을 쓸지" 정확히 알아챈다.
- `$ARGUMENTS` 자리에 내가 명령 뒤에 붙인 입력이 들어간다. 예: `/deploy production` → production이 전달됨.
- 반복되고 구조가 있는 작업에 쓰는 것이지, 일회성 질문까지 스킬로 만들 필요는 없다.
- frontmatter 옵션(`disable-model-invocation`, `allowed-tools` 등)으로 세밀한 제어도 가능 — 나중에 배워요.

## 따라해보기
1. 지금 쓸 수 있는 스킬 목록 보기 (클로드 코드 안에서)
   ```
   /
   ```
   → 슬래시만 치면 사용 가능한 명령/스킬 목록이 떠요.
2. 내 첫 스킬 만들기 (터미널에서)
   ```
   mkdir -p ~/.claude/skills/hello
   ```
   → 개인 스킬을 담는 폴더를 만들어요. 이 안에 SKILL.md를 만들면 됩니다.
3. SKILL.md 내용 예시 (클로드에게 "만들어줘"라고 해도 돼요)
   ```
   ---
   name: hello
   description: 인사를 하면 한국어로 자기소개를 한다
   ---
   사용자에게 한국어로 친절하게 자기소개를 해라.
   ```
   → 저장 후 클로드 코드에서 `/hello`를 치면 이 매뉴얼대로 동작해요.

## 주의할 점 / 자주 헷갈리는 것
- 파일 이름은 반드시 `SKILL.md` (대문자). 폴더 이름이 스킬 이름이 돼요.
- description이 모호하면 자동 호출이 안 되거나 엉뚱한 때 호출돼요. "언제 쓰는지"를 구체적으로!
- 스킬은 "반복 작업용"이에요. 한 번만 할 일은 그냥 채팅으로 시키는 게 빨라요.
- SKILL.md는 짧게 유지하고, 긴 참고자료는 같은 폴더에 별도 파일로 두는 게 좋아요.
