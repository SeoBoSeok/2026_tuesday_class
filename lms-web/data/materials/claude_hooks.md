# 훅(Hooks) — 정해진 순간에 자동으로 실행되는 규칙
> 원본: claude_hooks.pdf · 난이도: ★★☆(곧 필요)

## 한 줄 요약
훅은 "클로드 코드가 어떤 일을 할 때마다 자동으로 같이 실행되는 명령"을 미리 등록해 두는 기능이다.

## 이게 뭐예요?
집 현관에 "문이 열리면 자동으로 불이 켜진다"는 센서를 달아 두는 것과 같아요.
클로드 코드 안에서도 "응답이 끝나면", "도구를 쓰기 직전에" 같은 특정 순간(이벤트)이 있는데,
그 순간마다 내가 정해 둔 명령(소리 내기, 검사하기 등)을 자동으로 실행하게 할 수 있어요.
한 번 설정해 두면 매번 직접 시키지 않아도 클로드가 알아서 지켜 줍니다.

## 핵심 정리
- 훅은 클로드 코드의 **생명주기 이벤트**(작업 흐름 중 정해진 순간)에 자동 실행되는 명령이다.
- 설정 파일은 `~/.claude/settings.json` (홈 폴더 안의 클로드 설정 파일)에 적는다.
- 자주 쓰는 이벤트 몇 가지:
  - `SessionStart`: 클로드 코드를 켜거나 다시 열었을 때
  - `UserPromptSubmit`: 내가 메시지를 보낸 직후, 클로드가 처리하기 전
  - `PreToolUse`: 클로드가 도구(파일 수정 등)를 쓰기 직전 — 위험하면 막을 수도 있음
  - `PostToolUse`: 도구 사용이 성공한 직후 (기록·검사용)
  - `Stop`: 클로드가 답변을 다 끝냈을 때
- 훅으로 할 수 있는 일: 규칙 강제, 보안 검사, 로그 남기기, 자동 포맷팅, 실행 전 안전장치 등.
- 흐름: 내 명령 → 클로드 코드 → [훅 발동 지점] → 내가 등록한 명령 실행 → 계속 진행/수정/차단.
- `SubagentStart`, `PreCompact`, `WorktreeCreate` 같은 고급 이벤트도 있지만 나중에 배워요.

## 따라해보기
1. 설정 파일 열어 보기 (지금 어떤 설정이 있는지 구경만)
   ```
   cat ~/.claude/settings.json
   ```
2. "답변이 끝나면 띵~ 소리 내기" 훅 예시 — settings.json에 아래처럼 추가 (Mac 전용)
   ```json
   { "hooks": { "Stop": [ { "hooks": [
     { "type": "command", "command": "afplay /System/Library/Sounds/Glass.aiff" }
   ] } ] } }
   ```
   → 클로드가 답변을 마칠 때마다 소리가 나서, 다른 일 하다가도 끝난 걸 알 수 있어요.
3. 클로드 코드 안에서 `/hooks` 입력
   → 설정 파일을 직접 고치지 않고 메뉴로 훅을 추가/확인할 수 있어요.

## 주의할 점 / 자주 헷갈리는 것
- settings.json은 JSON 형식이라 쉼표·괄호 하나만 틀려도 전체가 안 읽힐 수 있어요. 고치기 전에 백업!
- 훅은 "내가 시킨 명령"이 아니라 "자동으로 매번" 실행돼요. 무거운 명령을 걸면 매번 느려집니다.
- 훅을 새로 추가했는데 동작 안 하면, 클로드 코드를 껐다 켜고 `claude --debug`로 확인해 보세요.
- Git의 훅(pre-commit)과 이름이 비슷하지만 별개예요. 개념만 닮았습니다.
