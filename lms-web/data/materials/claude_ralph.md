# Ralph 루프 — 될 때까지 반복시키기
> 원본: claude_ralph.pdf · 난이도: ★★☆(곧 필요)

## 한 줄 요약
Ralph 루프는 클로드에게 같은 지시문을 계속 다시 먹여서, 목표를 달성할 때까지 스스로 반복 작업하게 만드는 플러그인입니다.

## 이게 뭐예요?
세탁기를 떠올려 보세요. 빨래가 깨끗해질 때까지 "헹굼"을 자동으로 반복하죠. Ralph 루프도 똑같이, 클로드가 "다 했어요" 하고 멈추려 할 때마다 "아직이야, 다시!" 하고 같은 과제를 돌려줍니다. 클로드는 코드를 고치고, 테스트하고, 실패하면 또 고치는 과정을 사람이 지켜보지 않아도 반복합니다. 이름은 심슨 가족의 랄프 위검에서 따왔는데, "포기하지 않고 계속 시도한다"는 뜻이 담겨 있어요.

## 핵심 정리
- 핵심 원리: `while true`(무한 반복) 개념 — 프롬프트(지시문)를 에이전트에게 계속 다시 먹임
- 구현 방식: Stop hook(클로드가 끝내려는 순간 가로채는 장치)이 종료를 막고 같은 지시문을 다시 넣어줌
- 한 번만 실행하면 됨 — 별도의 터미널 반복 스크립트 없이 현재 세션 안에서 알아서 돎
- `--completion-promise "COMPLETE"`: 클로드가 이 문구를 출력하면 "진짜 끝"으로 인정하고 루프 종료
- `--max-iterations 50`: 최대 50번까지만 반복 (안 걸면 무한 반복이라 주의)
- 철학: 한 번에 완벽 X → 반복하며 점점 좋아짐. 실패도 정보다. 좋은 지시문 쓰기가 성공의 열쇠

## 따라해보기
1. 클로드 코드 안에서 아래처럼 입력 — 할 일 목록 API를 완성될 때까지 반복 제작시킴
   ```
   /ralph-loop "할 일(todo) REST API를 만들어줘. CRUD, 입력 검증, 테스트 포함. 다 되면 COMPLETE 출력." --completion-promise "COMPLETE" --max-iterations 50
   ```
2. 루프를 중간에 멈추고 싶을 때
   ```
   /cancel-ralph
   ```

## 주의할 점 / 자주 헷갈리는 것
- `--max-iterations`를 안 정하면 기본이 무제한 — 비용과 시간이 계속 들 수 있으니 처음엔 꼭 숫자를 거세요
- "성공 기준이 분명한 일"(테스트 통과 등)에만 쓰세요. 디자인 결정처럼 사람 판단이 필요한 일에는 안 맞아요
- 한 번이면 끝나는 단순 작업에 쓰면 오히려 낭비입니다
- 루프가 도는 동안 클로드가 멈춘 것처럼 보여도 정상 — Stop hook이 일부러 종료를 막고 있는 거예요
