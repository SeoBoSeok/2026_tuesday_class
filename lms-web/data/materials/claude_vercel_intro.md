# Vercel 입문 — 내가 만든 웹사이트를 세상에 공개하기
> 원본: claude_vercel_intro.pdf · 난이도: ★★☆(곧 필요)

## 한 줄 요약
Vercel은 명령어 몇 번으로 내 컴퓨터의 웹 프로젝트를 전 세계에서 접속 가능한 사이트로 배포해 주는 클라우드 서비스입니다.

## 이게 뭐예요?
집에서 쿠키를 구웠다고 해도(코드 작성), 가게에 진열해야 손님이 사 먹을 수 있죠(배포). Vercel은 복잡한 서버 설정 없이 "진열"을 대신해 주는 가게 같은 서비스예요. 터미널에서 `vercel` 한 단어만 치면 코드를 올리고, 빌드하고(실행 가능한 형태로 조립), 주소(URL)까지 만들어 줍니다. 전 세계 어디서나 빠르게 열리도록 CDN(세계 곳곳에 복사본을 두는 전송망)과 보안 연결(HTTPS)도 자동으로 챙겨줘요.

## 핵심 정리
- 프론트엔드(눈에 보이는 웹 화면) 프로젝트 배포에 특화된 클라우드 플랫폼
- 설정이 거의 필요 없음(zero-configuration) + HTTPS 자동 + 전 세계 CDN 기본 제공
- Next.js, React, Vue, Svelte, 정적 사이트 등 대부분의 웹 프레임워크 지원
- 기본 흐름: 내 코드 → Vercel CLI(터미널 명령 도구) → Vercel 플랫폼 → 전 세계 배포
- `vercel` = 미리보기(preview) 배포: 테스트용 임시 주소가 생김
- `vercel --prod` = 프로덕션(production, 실제 서비스) 배포: 진짜 공개 주소에 반영
- GitHub와 연동하면 커밋(저장)할 때마다 미리보기 사이트가 자동 생성 — 나중에 배워요

## 따라해보기
1. Vercel CLI 설치 후 버전 확인 — 설치가 잘 됐는지 점검
   ```
   npm install -g vercel
   vercel --version
   ```
2. 로그인 — 브라우저가 열리며 계정 인증 (이메일 또는 GitHub 계정)
   ```
   vercel login
   ```
3. 프로젝트 폴더 안에서 배포 — 질문 몇 개에 답하면 업로드→빌드→배포 완료, 주소가 출력됨
   ```
   vercel
   ```

## 주의할 점 / 자주 헷갈리는 것
- `vercel`(미리보기)과 `vercel --prod`(실서비스)는 다른 주소에 배포돼요 — "왜 실제 사이트가 안 바뀌지?"의 단골 원인
- 반드시 프로젝트 폴더 "안에서" 명령을 실행하세요 — 엉뚱한 폴더면 엉뚱한 게 올라갑니다
- 비밀값(API 키 등)은 코드에 적지 말고 환경 변수로: `vercel env pull`로 .env 파일에 내려받아 씁니다
- 배포가 이상하면 `vercel ls`(배포 목록), `vercel logs <배포주소>`(에러 기록 보기)로 확인하세요
