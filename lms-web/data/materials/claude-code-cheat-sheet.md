# Claude Code 치트시트 (명령어 한눈에 보기)
> 원본: Claude Code Cheat Sheet.pdf · 난이도: ★★☆(곧 필요)

## 한 줄 요약
Claude Code의 단축키·슬래시 명령어·설정 파일을 한 장에 모아둔 "참고용 커닝페이퍼"로, 외우지 말고 필요할 때 찾아보면 된다.

## 이게 뭐예요?
게임을 처음 살 때 들어있는 "조작법 카드" 같은 거예요. Claude Code에는 수십 개의 명령어와 단축키가 있는데, 이걸 전부 외울 필요는 없어요. 이 시트는 자주 쓰는 것들을 분류해서 한 페이지로 정리한 자료예요. 처음에는 아래 "핵심 정리"의 몇 가지만 알면 충분하고, 나머지는 궁금할 때마다 시트에서 찾아보세요.

## 핵심 정리
- **슬래시 명령어**(`/`로 시작하는 명령): `/clear` 대화 초기화, `/init` 프로젝트 파악(CLAUDE.md 생성), `/model` 모델 바꾸기, `/cost` 사용량 확인, `/permissions` 권한 관리, `/help` 도움말
- **접두사 3가지**: `/` 슬래시 명령, `!` 터미널 명령 직접 실행, `@` 파일 지정(자동완성 지원)
- **단축키**: `Ctrl+C` 생성 중단, `Ctrl+D` 종료, `Esc Esc` 되돌리기(rewind), `Shift+Tab` 권한 모드 전환
- **기억 파일**: `CLAUDE.md` — 프로젝트 설명을 적어두면 Claude가 매번 읽고 시작함 (프로젝트용 `./CLAUDE.md`, 개인 전체용 `~/.claude/CLAUDE.md`)
- **설정 파일**: `~/.claude/settings.json`(내 전체 설정), `.claude/settings.json`(프로젝트 공유 설정)
- **터미널 실행 명령**: `claude` 대화 시작, `claude -c` 직전 대화 이어가기, `claude update` 업데이트
- MCP, 서브에이전트, SDK 같은 고급 항목도 시트에 있어요 — 나중에 배워요.

## 따라해보기
1. `claude` — Claude Code 실행 (모든 것의 시작)
2. 실행 후 `/help` 입력 — 사용 가능한 명령어 목록을 직접 확인
3. `/cost` 입력 — 이번 세션에서 쓴 토큰·비용을 확인

## 주의할 점 / 자주 헷갈리는 것
- `/`는 Claude Code에게 주는 명령, `!`는 컴퓨터(셸)에 주는 명령이에요. 역할이 달라요.
- 치트시트의 명령을 다 외울 필요 없어요. ★ 지금은 `/init`, `/model`, `/cost`, `/permissions`, `/clear` 정도면 충분해요.
- 버전이 올라가면 명령이 추가/변경될 수 있어요. `/release-notes`로 변경 사항을 볼 수 있어요.
- `--dangerously-skip-permissions` 같은 플래그는 모든 안전장치를 끄는 옵션이니 초보 단계에서는 쓰지 마세요.
