간격 반복 복습 세션을 진행한다. 대상 학생: $ARGUMENTS (비어 있으면 물어본다)

## 준비
1. `date +%Y-%m-%d`로 오늘 날짜를 확인한다.
2. `lms/review/cards.md`에서 `다음 복습일 <= 오늘`이고 상태가 `활성`인 카드를 모은다. 없으면 "오늘 복습할 카드가 없어요 🎉"라고 알리고 다음 복습 예정일을 보여준다.
3. 카드가 6장을 넘으면 박스가 낮은(취약한) 순으로 6장만 고르고, 비슷한 개념은 연달아 내지 말고 섞는다(교차 연습).

## 퀴즈 진행 (카드 한 장씩)
1. 인출 질문만 보여주고 학생이 **먼저 답하게 한다**. 절대 답을 먼저 보여주지 않는다 (인출 연습).
2. 학생 답을 들으면: 맞으면 칭찬 + 정답 요지 확인, 틀리거나 모호하면 `lms/log/questions.md`의 답변 요지로 다시 설명한다.
3. 맞힌 카드는 정답 확인 후 "왜 그럴까요?" 또는 실제 상황 응용 질문을 하나 덧붙인다 (정교화).
4. 결과를 기록한다:
   - **맞음**: 박스 +1, 다음 복습일 = 오늘 + (박스1:1일 / 2:3일 / 3:7일 / 4:14일 / 5:30일). 박스 5에서 맞히면 상태를 `졸업`으로.
   - **틀림/모호**: 박스 = 1, 다음 복습일 = 오늘+1일.
5. `cards.md` 표를 갱신하고, 하단 "복습 이력" 표에 한 줄 추가한다.

## 마무리
- 결과 요약: 맞음/틀림 개수, 졸업 카드, 다음 복습 예정일.
- 반복해서 틀린 개념(이력에 2회 이상 오답)이 있으면 해당 학생 프로필(`lms/students/`)의 "취약 개념"에 기록하고, 강사에게 재설명을 제안한다.
