description: 학생 질문 기록 — 답변 후 질문 로그 + 복습 카드 자동 생성
---

학생 질문을 처리한다. 질문: $ARGUMENTS

1. **답변**: 초보자 눈높이로 답한다 — 한 문장 정의 → 쉬운 비유 → 짧은 예시 순서. 전문 용어가 또 나오면 그것도 한 줄로 풀어준다.
2. **로그 기록**: `lms/log/questions.md` 맨 아래에 다음 번호(Q###)로 추가한다. 오늘 날짜(`date +%Y-%m-%d`로 확인), 학생 이름($ARGUMENTS에 학생A/학생B가 있으면 그 학생, 없으면 "공통"), 질문, 답변 요지(2~3문장), 관련 챕터를 기록한다.
3. **복습 카드 생성**: `lms/review/cards.md` 표에 다음 번호(C###)로 카드를 추가한다. 인출 질문은 답을 그대로 묻지 말고 "설명해보세요/차이는?/비유로 말해보세요" 형태로 만든다. 박스 1, 다음 복습일 = 오늘+1일, 상태 = 활성.
4. 비슷한 카드가 이미 있으면 새로 만들지 말고 기존 카드를 알려준다.
5. 마지막에 "📝 Q### 기록, 복습 카드 C### 생성 (다음 복습: 날짜)" 한 줄로 확인시킨다.
