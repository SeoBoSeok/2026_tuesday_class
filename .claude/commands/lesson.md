오늘 수업을 시작한다. 다음 순서로 진행하라:

1. `first/`와 `first-commit/` 두 저장소에서 `git status`와 `git log --oneline -5`를 실행해 지난 수업 이후 변경 사항을 확인한다.
2. 원격(GitHub)에 새 커밋이 있는지 `git fetch` 후 로컬과 비교한다. 차이가 있으면 학생에게 알려주고 `git pull` 여부를 물어본다.
3. 두 프로젝트의 현재 상태를 초보자 눈높이로 각각 2~3문장으로 요약한다.
3-1. `lms/review/cards.md`에서 오늘 기준 복습 기한이 지난 카드가 있는지 확인하고, 있으면 개수를 알려주며 수업 첫 10분 `/review` 복습을 제안한다 (망각곡선 — 새 진도 전에 복습 먼저).
4. 학생에게 "오늘은 무엇을 만들거나 배우고 싶은지" 물어본다. $ARGUMENTS 에 주제가 적혀 있으면 그 주제로 바로 시작한다.
5. 주제가 클로드 코드 기능 학습이면 `2026_claude_lecture_pamforest/`에서 해당 챕터를 찾아 그 교안 기준으로 설명한다.

CLAUDE.md의 수업 운영 원칙(한 번에 한 개념, 실행 확인 후 다음 단계)을 반드시 지켜라.
