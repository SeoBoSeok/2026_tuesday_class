---

오늘 작업한 내용을 GitHub에 공유한다. 다음 순서로 진행하라:

1. 현재 디렉토리가 학생 저장소(`first/` 또는 `first-commit/`)인지 확인한다. 아니면 어느 저장소를 공유할지 물어본다.
2. `git status`와 `git diff`로 변경된 파일을 보고, **무엇이 바뀌었는지 초보자 눈높이로 요약**해서 보여준다.
3. 커밋에 포함하면 안 되는 파일(`node_modules`, `.env`, `.DS_Store` 등)이 섞여 있으면 알려주고 `.gitignore` 처리를 제안한다.
4. 한국어로 "무엇을 왜" 형식의 커밋 메시지를 제안하고, 학생 확인을 받은 뒤 커밋한다.
5. 푸시 전에 "GitHub에 올리면 상대 학생도 볼 수 있다"는 점을 알려주고, 확인을 받은 뒤 `git push` 한다.
6. 푸시가 끝나면 GitHub 저장소 주소를 알려주며 브라우저에서 확인하는 방법을 한 줄로 안내한다.

절대 force push 하지 말 것. 커밋·푸시는 반드시 학생 확인 후에만.
