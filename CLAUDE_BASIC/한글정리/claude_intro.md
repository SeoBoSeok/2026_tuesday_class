# Claude 소개 — 왜 Claude인가?
> 원본: claude_intro.pdf · 난이도: ★☆☆(지금 필요)

## 한 줄 요약
Claude는 Anthropic이 만든 AI로, 긴 문서 이해·자연스러운 글쓰기·꾸준한 추론에 특히 강하고, 코딩 벤치마크에서도 최상위 성적을 내는 모델이다.

## 이게 뭐예요?
Claude는 ChatGPT 같은 대화형 AI의 한 종류예요. 비유하자면, ChatGPT가 "빠르고 아는 게 많은 친구"라면 Claude는 "두꺼운 보고서를 끝까지 읽고 차분하게 같이 고민해주는 동료"에 가까워요. 단순히 답만 던져주는 게 아니라 "함께 생각해주는(thinking with you)" 것이 강점이에요. OpenAI 출신 연구자들이 세운 Anthropic이라는 회사가 만들었고, 안전성(Safety)·신뢰성(Reliability)·긴 문맥 추론(Long-context reasoning)에 집중해요.

## 핵심 정리
- 만든 회사: **Anthropic** — OpenAI 출신 연구자들이 창업, 안전·신뢰·긴 문맥에 집중
- Claude의 강점: 긴 문서 이해, PDF·설계문서·코드베이스 분석, 대화 중 맥락 유지(중간에 딴길로 덜 샘), 사람 같은 자연스러운 글("AI 티" 덜 남)
- 실무 활용 예: 30페이지 PDF 요약, 큰 pull request(코드 변경 요청) 리뷰, 메모를 깔끔한 제안서로 변환, 기술 문서를 비전문가용으로 다시 쓰기
- 벤치마크(모델 성능 시험) 성적 — Opus 4.6 기준:
  - Terminal-Bench 2.0 (터미널에서 개발자처럼 일하기): 65.4%로 1위
  - SWE-bench Verified (실제 GitHub 문제 해결): 80.8%
  - BrowseComp (웹에서 어려운 정보 찾기): 84.0%로 큰 격차 1위
  - OpenRCA (로그 보고 장애 원인 찾기): 34.9%
- ChatGPT와 비교: Claude는 긴 문맥·자연스러운 글·안정적 추론이 강점, ChatGPT는 속도·생태계 크기가 강점 — 우열보다 "스타일 차이"

## 따라해보기
1. `claude` — 터미널에서 Claude Code를 시작한다 (이 수업의 기본 도구)
2. Claude Code 안에서 `이 폴더에 어떤 파일이 있는지 설명해줘` 라고 입력 — Claude가 직접 파일을 읽고 답하는 것을 체험
3. PDF나 긴 글을 한 편 주고 `3줄로 요약해줘` — "긴 문서 이해" 강점을 직접 확인

## 주의할 점 / 자주 헷갈리는 것
- Claude(모델/챗봇)와 Claude Code(터미널에서 쓰는 도구)는 다른 제품이에요. 이 수업은 주로 Claude Code를 다룹니다.
- 벤치마크 숫자는 "시험 점수"일 뿐, 내 작업에서 항상 그대로 재현되는 건 아니에요.
- AI 답변은 틀릴 수 있어요. 중요한 내용은 꼭 직접 확인하세요.
- Opus/Sonnet/Haiku 같은 이름은 Claude 모델의 "등급(크기·성능)"이에요 — 자세한 건 /model 단원에서 배워요.
