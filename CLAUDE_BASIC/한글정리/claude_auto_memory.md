# 오토 메모리(Auto Memory) — 알아서 기억해주는 기능
> 원본: claude_auto_memory.pdf · 난이도: ★☆☆(지금 필요)

## 한 줄 요약
Auto Memory는 대화 중 쓸 만한 정보를 클로드가 **명령 없이 자동으로** 메모리 파일에 저장해주는 기능이다.

## 이게 뭐예요?
앞에서 배운 메모리는 "기억해줘"라고 직접 말해야 저장됐다면, Auto Memory는 클로드가 알아서 받아 적는 기능입니다. 회의 때 옆에서 **자동으로 회의록을 써주는 비서**라고 생각하면 됩니다. 비서가 중요한 결정만 골라 적고 잡담은 버리듯이, 클로드도 오래 쓸 정보(선호, 프로젝트 규칙)만 골라서 저장하고 일회성 내용은 저장하지 않습니다. 덕분에 다음 세션에서도 클로드가 나와 프로젝트를 기억한 상태로 시작합니다.

## 핵심 정리
- 저장 위치: `~/.claude/projects/<project>/memory/` 폴더. 핵심 파일은 `MEMORY.md`(요약 색인)이고, 상세 내용은 `debugging.md` 같은 주제별 파일로 나뉜다.
- `MEMORY.md`의 **첫 200줄만** 매 대화 시작 때 자동으로 로드된다. 200줄 이후 내용은 시작 시 안 읽힌다.
- 그래서 클로드는 `MEMORY.md`를 짧게 유지하고, 자세한 내용은 주제별 파일로 옮긴다.
- 200줄 제한은 `MEMORY.md`에만 적용. `CLAUDE.md`(프로젝트 지침 파일)는 길이와 상관없이 전부 로드되지만, 짧을수록 클로드가 더 잘 지킨다.
- 저장하는 것: 장기 선호, 지속 지시사항, 중요한 프로젝트 맥락. 저장 안 하는 것: 임시 정보, 일회성 대화 내용.
- 화면에 **"Writing memory"**(저장 중), **"Recalled memory"**(불러오는 중)가 보이면 클로드가 메모리 파일을 읽고 쓰는 중이라는 뜻.
- 동작 흐름: 대화에서 유용한 정보 감지 → `MEMORY.md`에 기록 → 주제별 파일로 정리 → 다음 세션 시작 때 다시 로드.

## 따라해보기
1. 클로드 코드에서 입력:
   ```
   /memory
   ```
   → `Auto-memory: on`인지 확인하고, "Open auto-memory folder"를 선택해 폴더를 직접 열어본다.
2. 터미널에서 메모리 파일 구경하기:
   ```
   ls ~/.claude/projects/
   ```
   → 프로젝트별 메모리 폴더가 어떻게 생겼는지 확인한다.
3. 클로드와 한참 작업한 뒤 `MEMORY.md`를 열어보기 → 무엇이 자동 저장됐는지 직접 확인.

## 주의할 점 / 자주 헷갈리는 것
- 내가 시키지 않아도 저장된다. 어떤 내용이 쌓이는지 가끔 폴더를 열어 확인하는 습관을 들이자.
- `MEMORY.md`가 200줄을 넘으면 뒷부분은 세션 시작 때 안 읽힌다. "분명 저장했는데 모르네?"의 흔한 원인.
- Auto Memory(자동 저장)와 `CLAUDE.md`(내가 직접 쓰는 지침 파일)는 서로 다른 파일이다.
- 모든 대화가 저장되는 게 아니다. "여러 세션에서 유용한 정보"라고 판단된 것만 저장된다.
