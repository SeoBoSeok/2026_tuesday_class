# MCP란? — 클로드에게 외부 도구 연결하기
> 원본: claude_mcp_cmd.pdf · 난이도: ★☆☆(지금 필요)

## 한 줄 요약
MCP는 클로드 코드에 외부 프로그램(데이터베이스, API 등)을 꽂아 쓰게 해주는 "USB 포트" 같은 연결 규격이다.

## 이게 뭐예요?
MCP(Model Context Protocol)는 클로드가 내 컴퓨터 밖의 세상과 대화할 수 있게 해주는 약속(프로토콜)이에요.
노트북에 USB로 마우스, 프린터, 외장하드를 꽂으면 바로 쓸 수 있듯이, 클로드에 MCP 서버를 "꽂으면" 그 서버가 가진 기능을 클로드가 바로 쓸 수 있어요.
예를 들어 날씨 API, 회사 데이터베이스, 깃 저장소 같은 것들이죠.
클로드 혼자서는 못 하는 일을, MCP를 통해 할 수 있게 됩니다.

## 핵심 정리
- MCP 서버는 클로드에게 세 가지를 제공한다:
  - **Tools**: 클로드가 호출할 수 있는 기능 (예: `add(3, 5)` 계산 — "무언가를 실행하는 버튼")
  - **Resources**: 읽기 전용 데이터 (예: `demo://hello` — "읽기만 하는 자료")
  - **Prompts**: 재사용 가능한 명령 템플릿
- 설정 방법은 두 가지 측면이 있다:
  - `/mcp` — 클로드 코드 대화창 안에서 쓰는 명령. MCP 서버 상태 확인, 로그인(OAuth 인증) 처리
  - `claude mcp ...` — 터미널에서 쓰는 명령. 서버 추가/목록/삭제 등 설정 담당
- 설정이 저장되는 위치(scope, 적용 범위):
  - 사용자 전체: `~/.claude.json` (내 컴퓨터 모든 프로젝트에 적용)
  - 프로젝트 전용: 프로젝트 폴더의 `.mcp.json` (팀원과 공유 가능)
- 파이썬으로 간단한 MCP 서버도 직접 만들 수 있다 (FastMCP 라이브러리 사용)
- 인기 MCP 서버 목록: https://code.claude.com/docs/en/mcp#popular-mcp-servers

## 따라해보기
1. `claude mcp list`
   - 지금 등록된 MCP 서버 목록을 보여준다.
2. `claude mcp get <서버이름>`
   - 특정 서버의 상세 설정을 보여준다. (이름은 1번 결과에서 골라 넣기)
3. 클로드 코드 대화창에서 `/mcp` 입력
   - 연결된 MCP 서버 상태를 확인하고, 로그인이 필요한 서버에 로그인할 수 있다.

## 주의할 점 / 자주 헷갈리는 것
- `/mcp`(대화창 안)와 `claude mcp`(터미널)는 다른 명령이다. 슬래시가 붙으면 클로드 코드 안에서 쓰는 것!
- 서버 추가 명령은 형식이 정해져 있다: `claude mcp add --transport stdio 이름 -- 실행명령` — `--` 뒤에 실제 실행 명령이 온다.
- 직접 MCP 서버를 만들 때 `print()`를 쓰면 통신이 깨진다(stdout이 통신 통로라서). 이건 나중에 서버를 직접 만들 때 배워요.
- MCP는 "기능 연결", Skill은 "일하는 방법" — 서로 다른 개념이다 (claude_mcp_skills.md 참고).
