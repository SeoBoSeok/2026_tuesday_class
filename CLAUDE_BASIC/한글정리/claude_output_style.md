# 출력 스타일(/output-style) — 클로드의 "성격" 바꾸기
> 원본: claude_output_style.pdf · 난이도: ★☆☆(지금 필요)

## 한 줄 요약
`/output-style`은 클로드 코드가 일하고 말하는 방식 자체를 바꾸는 스위치로, 초보자에겐 특히 Learning 모드가 유용하다.

## 이게 뭐예요?
같은 선생님이라도 "시험 감독 모드"와 "과외 모드"는 완전히 다르게 행동하죠?
`/output-style`은 클로드에게 어떤 모드로 일할지 정해 주는 명령이에요.
글씨 모양 같은 겉모습을 바꾸는 게 아니라, 클로드의 기본 행동 지침(시스템 프롬프트)을 통째로 갈아 끼우는 거예요.
그래서 설명을 많이 하게 만들 수도 있고, 나에게 직접 코드를 써 보게 시킬 수도 있습니다.

## 핵심 정리
- `/output-style`은 클로드 코드의 **시스템 프롬프트**(클로드가 항상 따르는 기본 행동 지침)를 교체한다.
- 단순한 말투 변경이 아니라 **행동 방식 자체**가 바뀐다 — "클로드가 자기 일을 무엇이라 생각하는지"를 재정의.
- 기본 제공 3가지 스타일:
  - **Default**: 빠르고 간결하게 일 처리. 설명 최소화. (실무용 기본값)
  - **Explanatory**: 왜 이렇게 했는지 이유를 풀어서 설명. (이해하며 배우고 싶을 때)
  - **Learning**: 단계별로 안내하고, 일부 코드는 나더러 직접 써 보라고 시킴. `TODO(human)` 표시를 남기기도 함. (수업·실습용)
- 직접 만들 수도 있다: `~/.claude/output-styles/이름.md` (개인용) 또는 프로젝트 안 `.claude/output-styles/` (프로젝트용).
- 커스텀 스타일 파일도 스킬처럼 frontmatter(name, description) + 지시문 형태 — 나중에 배워요.

## 따라해보기
1. 클로드 코드 안에서 스타일 선택 메뉴 열기
   ```
   /output-style
   ```
   → Default / Explanatory / Learning 중 화살표로 골라요.
2. Learning 모드로 바꾸고 아무 작업이나 시켜 보기
   ```
   /output-style  →  Learning 선택  →  "간단한 인사 웹페이지 만들어줘"
   ```
   → 클로드가 한 번에 다 해 주지 않고, 나에게 빈칸을 채우게 시키는 차이를 느껴 보세요.
3. 다 써 봤으면 Default로 되돌리기
   ```
   /output-style  →  Default 선택
   ```
   → 평소 작업할 땐 Default가 가장 빠르고 효율적이에요.

## 주의할 점 / 자주 헷갈리는 것
- 출력 스타일은 기본 지침을 **대체**해요. 바꾸면 클로드의 평소 간결한 작업 습관이 사라질 수 있어요.
- "왜 갑자기 말이 많아졌지?" 싶으면 출력 스타일이 바뀐 상태인지 먼저 확인하세요.
- Learning 모드에서 `TODO(human)`이 보이면 버그가 아니라 "여기는 네가 채워 봐"라는 뜻이에요.
- CLAUDE.md(메모리)와 달라요: CLAUDE.md는 지침을 *추가*하고, 출력 스타일은 기본 지침을 *교체*합니다.
