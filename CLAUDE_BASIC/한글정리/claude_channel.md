# 채널(Channels) — 밖에서 클로드에게 말 걸기
> 원본: claude_channel.pdf · 난이도: ★★★(나중에)

## 한 줄 요약
채널은 텔레그램·디스코드 같은 외부 서비스가 지금 켜져 있는 클로드 코드 세션에 실시간으로 메시지를 보낼 수 있게 해주는 기능입니다.

## 이게 뭐예요?
사무실 책상에 앉아 일하는 비서(클로드)에게 인터폰을 달아주는 것과 같아요. 인터폰(채널)이 생기면 여러분이 외출 중에도 휴대폰으로 "그 작업 어떻게 됐어?"라고 물어볼 수 있고, 빌딩 경비 시스템(CI/CD 같은 자동화 도구)이 "문제 발생!"이라고 알려주면 비서가 즉시 대응할 수 있죠. 컴퓨터 앞에 없어도 클로드가 이벤트를 받아 일하게 만드는 구조입니다.

## 핵심 정리
- 외부 시스템 → 실행 중인 클로드 코드 세션으로 메시지를 "밀어 넣는" 구조 (실시간)
- 새 세션을 만들 필요 없이, 지금 쓰던 세션 안에서 그대로 동작
- 이벤트 기반(event-driven): 클로드가 계속 확인하러 가는 게 아니라, 일이 생기면 알림이 옴
- 지원 채널: Telegram, Discord, iMessage + MCP(외부 연결 규격)로 직접 만드는 커스텀 채널
- 양방향 대화 가능: 휴대폰에서 보내면 클로드가 답장도 휴대폰으로 보냄
- 보안: 허가된 사람만 보낼 수 있음(allowlist) + 처음에 페어링(기기 등록 같은 인증) 필요
- 회사 계정에서는 기본 꺼져 있고 관리자가 켜야 함

## 따라해보기
1. 채널 플러그인 설치 후, 채널을 켠 상태로 클로드 코드 시작하기
   ```
   claude --channels plugin:telegram
   ```
2. (설치된 경우) 텔레그램 봇 연결 설정 — 봇 토큰을 등록하고 접근 정책을 정함
   ```
   /telegram:configure
   ```

## 주의할 점 / 자주 헷갈리는 것
- 클로드 세션이 꺼져 있으면 메시지를 못 받아요 — "세션이 살아 있는 동안"만 동작합니다
- 답장은 터미널이 아니라 보낸 쪽 플랫폼(텔레그램 등)에 표시됩니다 — 터미널만 보고 "왜 답이 없지?" 하지 마세요
- 아무나 메시지를 보내 클로드를 조종하면 위험! 꼭 허용 목록과 페어링 인증을 거치세요
- 봇 토큰 발급 등 사전 설정이 필요해서 초보 단계에선 급하지 않아요 — 기본기를 익힌 뒤에 도전하세요
