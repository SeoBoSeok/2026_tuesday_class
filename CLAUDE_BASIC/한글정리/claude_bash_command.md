# ! 명령 — Claude Code 안에서 터미널 명령 바로 실행
> 원본: claude_bash_command.pdf · 난이도: ★☆☆(지금 필요)

## 한 줄 요약
명령 앞에 `!`를 붙이면 AI 해석 없이 진짜 터미널(bash) 명령으로 즉시 실행되고, 그 결과가 화면에 보이는 동시에 Claude의 기억(컨텍스트)에도 들어간다.

## 이게 뭐예요?
Claude Code 안에서 평소처럼 문장을 치면 AI가 "해석"해서 움직여요. 그런데 `!ls`처럼 느낌표를 붙이면 통역사를 거치지 않고 주방에 직접 주문서를 넣는 것과 같아요 — AI의 계획·고민 단계 없이 셸(shell, 터미널 명령을 실행하는 프로그램)에서 곧바로 실행됩니다. 숨은 강점은 그 실행 결과를 Claude도 같이 본다는 것! 그래서 에러가 나면 "방금 그 에러 고쳐줘"라고 바로 이어서 부탁할 수 있어요.

## 핵심 정리
- 문법: `!<bash command>` 예) `!pwd`, `!ls -al`, `!git status`
- 동작: AI 계획 없음 → 셸에서 즉시 실행 → 원본 출력 그대로 표시 (No AI planning, just execution + output)
- 일반 터미널과의 차이: 일반 터미널은 출력 결과를 **내가** 읽고 판단하지만, Claude Code의 `!`는 출력이 **Claude의 컨텍스트(대화 기억)에도 자동으로 들어감**
- 그래서 가능한 것: `!npm run build` 실패 → Claude가 에러를 읽고 "의존성 X가 없네요, npm install X 하세요"처럼 바로 진단 (자동 디버깅)
- 반복 루프: `!명령 실행 → 에러 → Claude가 출력 읽음 → 수정 제안` 을 빠르게 반복 가능
- 쓰기 좋은 순간: 빠른 확인(`!pwd`), git 작업(`!git status`), 환경 확인(`!env`), 이미 아는 명령 재실행(`!npm run dev`)

## 따라해보기
1. `!pwd` — 지금 내가 어느 폴더에 있는지 확인 (print working directory)
2. `!ls -al` — 현재 폴더의 파일 목록을 자세히 보기
3. `!git status` 실행 후 "방금 결과를 설명해줘"라고 입력 — 출력이 Claude의 컨텍스트에 들어갔다는 걸 직접 확인

## 주의할 점 / 자주 헷갈리는 것
- `!`는 셸 명령용, `/`는 Claude Code 내장 명령용이에요. `!init`(X) vs `/init`(O) 헷갈리지 마세요.
- `!` 뒤의 명령은 AI가 검토하지 않고 그대로 실행돼요. 삭제 명령(`rm` 등)은 신중하게!
- 명령 출력도 컨텍스트(토큰)를 차지해요. 출력이 어마어마하게 긴 명령을 자꾸 돌리면 비용·용량이 늘어요.
- 셸 명령 자체(ls, cd, git 등)를 모른다면 그냥 한국어로 "파일 목록 보여줘"라고 해도 돼요. `!`는 명령을 이미 아는 경우의 지름길이에요.
