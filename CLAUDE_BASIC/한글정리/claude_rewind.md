# /rewind — 대화 되감기 버튼
> 원본: claude_rewind.pdf · 난이도: ★☆☆(지금 필요)

## 한 줄 요약
`/rewind`는 대화를 과거의 특정 메시지 시점으로 되돌려, 잘못 간 방향을 지우고 거기서 다시 시작하게 해준다.

## 이게 뭐예요?
게임에서 보스전을 망치면 **세이브 포인트**로 돌아가서 다시 도전하죠? `/rewind`가 바로 그겁니다. 클로드와 대화하다가 내가 지시를 잘못 내렸거나 클로드가 엉뚱한 길로 빠졌을 때, 처음부터 새로 시작할 필요 없이 "여기까지는 좋았어" 하는 메시지를 골라 그 시점으로 되돌립니다. 선택한 지점 이후의 대화는 삭제되고, 세션이 그때 상태로 복원됩니다.

## 핵심 정리
- `/rewind` = 대화 상태를 이전 메시지 시점으로 **롤백(roll back, 되돌리기)**. 선택 지점 이후 내용은 삭제된다.
- 실행하면 돌아갈 메시지를 고르는 메뉴가 뜨고, "Restore conversation"(대화 복원) 등을 선택하면 된다. **코드 파일은 바뀌지 않는다**(대화만 되돌림).
- 되감으면 그 이후 메시지가 삭제되므로 토큰 사용량이 줄고 컨텍스트 창에 여유가 생긴다.
- 이럴 때 좋다: 잘못된 지시를 했을 때, 클로드가 목표를 오해했을 때, 불필요한 내용으로 컨텍스트를 오염시켰을 때, 다른 질문 방식을 실험하고 싶을 때.
- 이럴 땐 굳이 안 써도 된다: 사소한 정정(그냥 말로 고쳐주면 됨), 작은 다듬기.
- 나쁜 흐름: 잘못된 방향 → 프롬프트 추가 → 더 혼란 → 터미널 새로 켬 → 맥락 전부 잃음. 좋은 흐름: 잘못된 방향 → `/rewind` → 질문 고쳐 쓰기 → 깔끔하게 계속.
- 클로드 코드는 "AI의 상태 관리"이고, `/rewind`는 그중 **롤백 장치**다.

## 따라해보기
1. 클로드와 두세 마디 나눈 뒤 입력:
   ```
   /rewind
   ```
   → 과거 메시지 목록이 뜬다. 돌아갈 지점을 골라 "Restore conversation"을 선택해본다.
2. 일부러 연습해보기: 이상한 질문을 하나 던진 다음 `/rewind`로 그 직전으로 돌아가서, 같은 질문을 더 좋게 고쳐 다시 던져보기.
   → "되감기 → 질문 개선 → 재시도" 흐름을 몸에 익힌다.

## 주의할 점 / 자주 헷갈리는 것
- 되감은 지점 **이후의 대화는 사라진다.** 필요한 내용이 있으면 되감기 전에 복사해두자.
- `/rewind`는 대화만 되돌린다. 이미 수정된 코드 파일까지 자동으로 원상복구되는 건 아니니 파일 상태는 따로 확인.
- `/clear`(전부 삭제)와 다르다. `/rewind`는 **중간 지점까지만** 되돌리고 그 앞의 맥락은 유지한다.
- 두 가지 결과를 비교하고 싶을 땐 되감기보다 결과를 복사해두고 따로 비교하는 편이 낫다.
