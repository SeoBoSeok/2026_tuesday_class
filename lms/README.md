# 코코(KoKo) LMS — AI 에이전트와 함께하는 클로드코드 + 바이브코딩 학습 관리 시스템

**코코(KoKo)** = 클로드**코**드 + **코**칭. 수업 관리 에이전트(class-manager)의 이름이자 이 시스템의 브랜드다.
질문 기록 → 학습 추적 → 간격 반복 복습 → 코칭을 자동화하는 파일 기반 LMS.
별도 서버 없이 클로드 코드 자체가 LMS 엔진으로 동작한다.

## 교재 (Textbook)

- 통합 교재 (1~9장): https://docs.google.com/document/d/1fsd5bzc7KzLUa5ltEPXPzVFSPIow1GGUoi59zc7kt0w/edit

## 사용법 (강사용)

| 명령 | 하는 일 |
|------|---------|
| `/question 학생A 터미널이란?` | 질문에 답하고 → 질문 로그에 기록 → 복습 카드 자동 생성 |
| `/review` | 오늘 복습할 카드만 골라 퀴즈 진행 → 결과에 따라 다음 복습일 갱신 |
| `/progress` | 학생별 진도·취약 개념·복습 현황 리포트 |
| `/quiz-send` | 복습 카드에서 퀴즈를 만들어 웹 LMS에 게시 (`lms/quizzes/*.json`) |

## 수업 관리 에이전트 (class-manager)

`.claude/agents/class-manager.md` — 수업의 시작·진행·마무리 기록을 전담한다.

| 말하기 | 하는 일 |
|--------|---------|
| `/lesson` 또는 "수업 시작해줘" | 오늘 `classlog/YYYY-MM-DD.md` 생성, 저장소·복습 점검, 오늘 목표 기록 |
| "기록해줘: 학생A가 첫 커밋 성공" | 진행 기록에 시간과 함께 추가 |
| "수업 마무리해줘" | 기록 완성 → 진도표·복습 카드·학생 일지·**코칭 기록** 갱신 → **웹 자동 배포** |
| "학생A 코칭 기록해줘: ..." | 코칭 문서(`coaching/`)에 코멘트·기술 상태·로드맵 즉시 반영 |

## 학생별 코칭 (`coaching/`)

학생마다 코칭 문서 하나 — 웹의 학생 페이지 "🎓 선생님 코칭" 섹션에 그대로 표시된다.

- **프로젝트 완성 로드맵**: 체크박스로 진척 관리
- **필요한 기술·라이브러리**: 무엇을 왜 배우는지 + 상태(⬜ 예정/🔄 배우는 중/✅ 배움)
- **선생님 버전**: 비교하며 배울 참고 구현 링크
- **코치 세션**: 수업마다 쌓이는 성장 기록 (현재 상태/코멘트/다음 과제)
- **수시 코멘트**: 수업 외 시간에 남기는 피드백

## 웹 LMS (학생용 화면)

**🌐 배포 주소 (학생 공유용): https://lms-web-henna-six.vercel.app**

`../lms-web/`의 Next.js 앱이 이 폴더의 마크다운을 읽어 보여준다.

```bash
cd ../lms-web && npm run dev      # 로컬 실행 → http://localhost:3100
cd ../lms-web && npm run deploy   # 배포 갱신 (lms/ 변경분을 data/로 복사 후 Vercel 프로덕션 배포)
```

배포 구조: 읽기 데이터(질문·카드·진도·자료·퀴즈)는 파일로 함께 배포되고,
퀴즈 결과만 Vercel Blob(lms-quiz-results 저장소)에 저장된다.
**수업에서 lms/ 마크다운을 수정한 뒤에는 `npm run deploy`를 해야 웹에 반영된다.**
저장소: https://github.com/SeoBoSeok/2026_tuesday_class (커밋·푸시는 기록 보관용)

- **대시보드**: 진도·복습 알림·최근 질문 한눈에
- **학생 페이지**: 프로젝트 발전 타임라인(git 커밋), 퀴즈 성적, 다지는 중인 개념
- **자료실**: 한글 정리본 30편 검색·열람
- **퀴즈**: `/quiz-send`로 발송한 퀴즈 풀기 → 결과는 `quiz-results/`에 저장
- **질문 모음**: 질문 타임라인 + 어디를 진짜 궁금해하는지 분포 차트

수업 중 학생이 개념 질문을 하면 `/question` 없이도 Claude가 자동으로 기록한다 (루트 CLAUDE.md 규칙).

```

```

## 교육학 이론 근거

| 이론 | 적용 |
|------|------|
| **망각곡선** (Ebbinghaus) — 배운 직후 급격히 잊는다 | 배운 직후 1일 → 3일 → 7일 → 14일 → 30일 간격으로 복습 시점 배치 |
| **간격 효과** (Spacing Effect) — 몰아서보다 나눠서 복습이 오래 간다 | 라이트너 박스: 맞히면 간격 2배+, 틀리면 1일로 리셋 |
| **인출 연습** (Testing Effect) — 다시 읽기보다 떠올리기가 기억을 강화한다 | `/review`는 답을 보여주기 전에 반드시 학생이 먼저 답하게 한다 |
| **정교화 질문** (Elaborative Interrogation) — "왜?"를 설명하면 깊어진다 | 정답 확인 후 "그럼 ~는 왜 그럴까?" 한 단계 확장 질문 |
| **교차 연습** (Interleaving) — 주제를 섞어 복습하면 변별력이 생긴다 | 복습 세션에서 비슷한 개념(예: CLI/터미널/셸)을 섞어 출제 |
| **메타인지** — 자기 이해 상태를 아는 것 자체가 학습을 돕는다 | `/progress`에서 학생 스스로 취약 개념을 확인 |
