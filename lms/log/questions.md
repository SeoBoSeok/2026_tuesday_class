## Q001 · 터미널이란?
- **날짜**: 2026-06-12 이전 (기록 시작 전 누적분) · **학생**: 공통 · **챕터**: 00-시작하기
- **답변 요지**: 텍스트로 명령을 입력해 컴퓨터를 조작하는 프로그램(창). 마우스로 클릭하는 대신 글자로 명령한다. 정확히는 "터미널 앱"이 창을 띄우고, 그 안에서 명령을 해석하는 프로그램은 셸(zsh 등)이다.

## Q002 · 터미널과 iTerm의 차이점은?
- **날짜**: 2026-06-12 이전 · **학생**: 공통 · **챕터**: 00-시작하기
- **답변 요지**: 둘 다 "터미널 앱"이다. Terminal.app은 macOS 기본 내장, iTerm2는 따로 설치하는 고급 터미널 앱(분할 화면, 검색, 테마 등 기능이 더 많음). 안에서 하는 일은 같다.

## Q003 · 클로드코드 터미널은 뭔가?
- **날짜**: 2026-06-12 이전 · **학생**: 공통 · **챕터**: 00-시작하기
- **답변 요지**: 클로드 코드는 별도의 터미널이 아니라, 터미널 안에서 `claude` 명령으로 실행하는 CLI 프로그램이다. 어떤 터미널 앱(Terminal, iTerm2, VSCode 내장 터미널)에서든 실행할 수 있다.

## Q004 · CLI란?
- **날짜**: 2026-06-12 이전 · **학생**: 공통 · **챕터**: 00-시작하기
- **답변 요지**: Command Line Interface. 글자(명령줄)로 프로그램을 조작하는 방식. 반대말은 GUI(Graphical UI, 마우스로 클릭). 클로드 코드는 CLI 프로그램이다.

## Q005 · CLI 명령어에서 '--'의 의미는?
- **날짜**: 2026-06-12 이전 · **학생**: 공통 · **챕터**: 01-기본-사용법
- **답변 요지**: 옵션(플래그)을 나타내는 표시. 긴 이름 옵션은 `--`(예: `--version`), 한 글자 축약형은 `-`(예: `-v`). 명령의 동작 방식을 바꾸는 스위치라고 생각하면 된다.

## Q006 · claude랑 claude code의 차이점은?
- **날짜**: 2026-06-12 이전 · **학생**: 공통 · **챕터**: 00-시작하기
- **답변 요지**: Claude는 AI 모델(그리고 claude.ai 챗 서비스)의 이름. Claude Code는 그 Claude 모델을 터미널에서 코딩 도우미(에이전트)로 쓰게 해주는 도구다. 비유: Claude가 엔진이라면 Claude Code는 그 엔진을 단 작업차.

## Q007 · MCP와 API의 차이점은?
- **날짜**: 2026-06-12 이전 · **학생**: 공통 · **챕터**: 09-MCP
- **답변 요지**: API는 프로그램끼리 대화하는 약속(규약)의 일반 명칭. MCP는 그중에서도 "AI에게 외부 도구를 연결하는 표준 규격"이다. 비유: API가 "전기 쓰는 법" 전반이라면 MCP는 "USB-C 규격"처럼 AI용으로 통일된 연결 단자. MCP 서버가 내부적으로 일반 API를 호출하는 경우가 많다.

## Q008 · brew --cask 할 때 cask의 의미는?
- **날짜**: 2026-06-12 이전 · **학생**: 공통 · **챕터**: 00-시작하기
- **답변 요지**: Homebrew에서 GUI 앱(크롬, iTerm2 같은 .app)을 설치할 때 쓰는 구분. cask는 "술통"이라는 뜻으로, CLI 도구를 담는 formula(제조법)와 구분해 완성품 앱을 통째로 담아 설치한다는 비유. `brew install`은 CLI 도구, `brew install --cask`는 GUI 앱.
